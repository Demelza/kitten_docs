# Kitten AFK Pad
The AFK pad is an object that can be rezzed on the ground and will act as your "home furniture". You will need to set it as your first FURNITURE line in the configuration notecard of your tip jar.

## Scripts
The AFK pad contains a few scripts to enhance its functionality, as follows:

* Furniture script (kitten.furniture): for your convenience, the furniture script has already been placed inside the AFK pad. It is the same furniture script that is provided with your purchase of the Kitten AFK system, so in case you delete it by mistake, you can simply drag another copy inside. This script can NOT be removed without breaking core functionality.

* Face Reset script (kitten.facereset): this script will reset your face expression if you have a compatible head (currently compatible with Utilizator M4 heads only) and the face controls script in the AFK Controls worn object. It is useful in case your clients don't reset it themselves, so that you can be returned to a more neutral appearance. It uses the settings from the Face Controls (available separately on the Marketplace) if they are present in your AFK Controls worn object. This script CAN be removed without breaking core functionality. Simply remove the kitten.facereset script.
    Please note that the face reset script will only work if the AFK Controls object equipped contains the kitten.facecontrols script and its notecard. This script comes with a different purchase of this product: https://marketplace.secondlife.com/p/Midoris-Stuff-M4-Universal-Face-Expression-Clicker/28627062

* Cleaner script (kitten.cleaner): this script will clean cum left on your body and face by your clients once they're done playing with you and you are returned to the AFK pad. It is currently only compatible with the Spunked cum system. This script CAN be removed without breaking core functionality. Simply remove the kitten.cleaner script.

* Redresser script (kitten.redress): this script will read your current outfit and redress you with it when you are returned to the AFK pad, in case your clients don't redress you after playing. This script CAN be removed without breaking core functionality. Simply remove the kitten.redress script.

It is also possible to use your own AFK pad/home furniture instead of the provided one. In this case, the kitten.facereset, kitten.cleaner and kitten.redress scripts may be copied to the new home furniture without breaking their functionality.
